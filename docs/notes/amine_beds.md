# CO₂ Scrubbing (Amine Swing Beds) 
### General Notes:
    ♡ removes CO₂ from the cabin atmosphere

    ♡ uses amine swing beds to absorb, regenerate, and cycle

    ♡ multiple beds so some can adsorb while others regenerate

    ♡ includes primary beds plus backups

    ♡ heat is produced during absorption and regeneration

    ♡ power scales with how much CO₂ is being processed

    ♡ lives in the Utility / Resource Recovery Hub (see atmosphere.md)
