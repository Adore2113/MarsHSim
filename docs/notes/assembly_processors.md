# Assembly Processors (UPA / WPA / BPA)
### General Notes:
    ♡ three core water recovery assemblies that form the heart of the closed-loop system
    
    ♡ all three share the same control pattern: offline / idle / running + hysteresis + load based power scaling
    
    ♡ heat added to the habitat thermal balance is modelled as ~ 85 % of electrical power
    
    ♡ units only run when the relevant tank exceeds the hysteresis threshold
    
    ♡ realistic (non-perfect) recovery rates
    
    ♡ power and capacity numbers are intentionally conservative for V1
